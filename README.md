# 自訂星球與任務組

適用 HellForge SDK 16、Helldivers 2 構建 25480438。目前版本 `0.3.0-test22`。

只有房主需要安裝，客機不用。房主匯入 `dist/host-ops-test-<版本>.zip`，並啟用 `local.host-ops-test`。直接用原本的戰況就可以，不需要開啟全星球預設。

## 開啟選單

在自己的艦船上按 **F11** 開關選單，按 **Esc** 也能關閉。選單畫在遊戲畫面裡，操作方式和 HellForge 的 F8 編輯器一樣：

- **選單開著：** 鍵盤和滑鼠只給選單用。
- **選單關著：** 遊戲原本的滑鼠和視角邏輯完全不受影響。

右上角可以切換**繁體中文、简体中文、English**，選擇會被記住。任務組、任務、陣營、星球和部分詞條，會用遊戲本身的官方譯名。搜尋時打英文、繁體或簡體都找得到。

## 設定步驟

1. **入口星球：** 輸入名稱或編號（例如 `#1`），點選結果。這是戰術桌上要進入的星球，必須是戰況裡有的星球。火星（#263）目前還不能當入口。
2. **地形來源：** 可以保留原版地形，也可以換成任一份地形，共 438 份，包括沒綁在星圖上的地形，例如 `planet_313`、針葉林、寂域森林、火星訓練場。直接打完整的 hash 數字，也可以用清單外的地形。沒有星球名稱的地形，進任務後可能顯示「保密地點」。
3. **行動設定：** 選任務組（共 25 個範本），陣營會跟著範本走。選「原版生成」時，陣營可以自己指定。難度由戰術桌決定，模組不會更動。每個難度的任務卡都會套用所選範本，遊戲產生不出來的那張卡維持原版。
4. **星球詞條：** 搜尋名稱或效果 ID，可以勾選單一詞條或整組變種。會和星球原有的詞條合併，重複的只算一次。每顆星球最多 32 個不同 ID，原有的也算在內。每個詞條後面會標出客機能不能用：
   - [客機可見]：HellForge 內建 24 個定義之一；
   - [客機部分可見]：組合裡只有部分 ID 有定義；
   - [客機顯示?]：沒有定義。

   多人遊戲只用「客機可見」的詞條，分類選單可以只列出這些。
5. **自定義任務：** 點「任務 1／2／3」選一格，再從遊戲任務表的全部 162 個任務裡挑一個。清單會標出陣營、模式、難度、任務列號，沒被任何任務組用到的標 [隱藏]，停用的標 [停用]。
   - 實際有幾個任務由難度決定，依序取任務 1、2、3。
   - 選和任務組不同陣營的任務，可能產生不出來，或進去後出錯。
   - **只有主機的遊戲會換任務。** 沒裝本模組的客機，仍然照任務組和種子計算任務，兩邊會不一致。請單人玩，或讓所有人都裝同一版模組。
6. **開放：** 核對摘要後，選一種方式開放：
   - **臨時開放**：有效到按「撤回開放」或關閉遊戲為止。
   - **保存並開放**：下次開遊戲會自動套用。
   - **撤回開放**：取消開放，並清除已保存的預設。

   關掉選單後，到戰術桌進入第 1 步選的星球。

   修改會立刻套用，不用等目前的行動結束（test22 起）。中途退出任務後回到飛船，可以直接改設定再進下一個任務；已經建立的行動維持原本的任務組和任務，新的任務卡才會用新設定，地形和詞條則立刻套到進行中的行動上。行動結束後（完成、放棄或中途退出），星球都會維持開放，可以直接開下一個行動。

## 同步碼：讓裝了本模組的朋友套用同樣的修改

選單最下面有兩個按鈕：
- **複製同步碼：** 把目前的整份設定複製到剪貼簿，包括星球、地形、陣營、任務組、任務 1–3 和詞條。同步碼長得像 `HF1-05WG0BQN…`。
- **貼上同步碼並套用：** 讀入剪貼簿裡的同步碼，直接套用全部設定。

**用法：**
1. 房主設定好、開放後，按「複製同步碼」，把碼傳給朋友。
2. 朋友也裝同一版模組，按 F11 後按「貼上同步碼並套用」。在自己的飛船上，或已經加入房間後都可以；客機也能開選單。
3. 朋友成為客機後，模組會照同一份設定修改他自己的遊戲：任務 1–3 換成同樣的任務；那顆星球的行動進行中時，寫入同樣的地形、陣營和詞條。
4. 要停止時，按「撤回開放」。

**限制：**
- 只對同一顆星球、同一個行動有效。
- HellForge 沒定義的詞條，兩邊都寫入也不會生效。
- 如果加入時任務已經產生好了，可能要等下一個行動才會換。

## 客機能同步的範圍

| 設定 | 沒裝本模組的客機 |
|---|---|
| 入口星球、任務組 | 會同步：客機照範本編號和種子算出同樣的行動 |
| 地形 | 其他修改器的使用者回報可以；本模組還沒用兩台機器驗證 |
| 星球詞條 | **本模組尚未驗證。** 房主端已確認進任務時帶著所選 ID（例如 `1303`、`1310`），但客機有沒有收到、會不會刷出變種敵人，都還不知道。<br>早期用參考模組 0.2.0 測試時，客機星圖上出現紫色問號；這表示客機可能收到了 ID，只是沒有對應的定義。<br>每台遊戲只認得自己後端的詞條定義，HellForge 0.4.0-beta 內建 24 個。<br>變種通常是一對 ID：例如破地變種的 `1303`（type 40）負責讓變種敵人能出現，`1310`（type 71）負責星圖標記。<br>客機後端也會依自己的種子分配變種，可能和房主不同。 |
| 自定義任務 1–3 | **不會同步**；裝了本模組的朋友貼上同步碼就會一致 |

## 日誌

日誌在 HellForge 的 `logs/sessions/<會話>/mod-local.host-ops-test.log`，時間是 UTC。可以搜尋這些關鍵字：

| 關鍵字 | 內容 |
|---|---|
| `Generated native candidate` | 候選任務卡的星球、範本、設定 ID、難度 |
| `Mission N of planet` | 自定義任務替換了第幾格、換成哪個任務 |
| `operation created` | 實際建立的行動 |
| `mission start` | 進任務時讀到的地形（`(this mod's)` 代表是模組設定的）和詞條 |
| `Operation on planet … ended` | 行動結束後，星球維持開放並重建戰況 |
| `F11 input` / `F11 raw` | 選單的輸入處理和遊戲的輸入註冊 |

客機、8 人房、中途加入的驗收項目見 [TEST.md](TEST.md)。技術細節和交接說明見 [AGENTS.md](AGENTS.md)。

## 建置

需要 Windows、Python、HellForge 附的 Zig，以及 Dear ImGui v1.91.8：到 https://github.com/ocornut/imgui/releases/tag/v1.91.8 下載原始碼，解壓縮成 `third_party/imgui-1.91.8`。

```powershell
python build.py --hf-root "F:\Game\A\HD2\HellForge" --warnings-as-errors
```

建好的套件在 `dist`。遊戲執行中時 HellForge 不能換模組，請先關閉遊戲再匯入。

以下資料表由 `tools/` 的腳本產生（腳本裡的路徑要改成你自己的遊戲和資料位置），遊戲更新後要重新執行：

| 資料表 | 產生方式 |
|---|---|
| `src/mission_catalog.c` | `dump_operation_tables.py`，再跑 `gen_mission_catalog.py` |
| `src/game_text.c` | `dump_strings.py`，再跑 `gen_game_text.py` |
